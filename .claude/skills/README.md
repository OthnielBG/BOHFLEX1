# Skills de design installées pour BOHFLEX

Instructions de travail utilisées par Claude pour améliorer le site (design, animations, rendu sur mobile).
Elles ne sont pas chargées par le site lui-même et n'ont aucun effet pour les visiteurs.

| Skill | Origine | Usage pour BOHFLEX |
|---|---|---|
| emil-design-eng | emilkowalski/skills (0f2e23b) | Finition générale, détails qui font « pro » |
| mobile-native | emilkowalski/skills | Rendre le site et l'application aussi fluides qu'une vraie app sur téléphone |
| animate, choreograph, animation-vocabulary | emilkowalski/skills | Créer des animations justes (durées, courbes, enchaînements) |
| animation-performance | emilkowalski/skills | Animations fluides même sur téléphone d'entrée de gamme |
| find-animation-opportunities, improve-animations, review-animations, remove-animations | emilkowalski/skills | Auditer : ajouter ce qui manque, retirer ce qui gêne |
| break-ui | emilkowalski/skills | Tester avec des cas extrêmes (noms longs, champs vides…) |
| learn-taste | emilkowalski/skills | Garder vos préférences de design en règles écrites |
| modern-web-design | freshtechbro/claudedesignskills (1da73fe) | Tendances et bonnes pratiques de design web |
| scroll-reveal-libraries | freshtechbro/claudedesignskills | Apparitions au défilement (pages de vente) |
| animejs | freshtechbro/claudedesignskills | Animations légères en JavaScript sans framework |

Non retenues : skills 3D (Three.js, Babylon, Blender…), React / React Native, Swift — inadaptées à un site
léger en HTML/CSS/JS destiné à la 3G.
